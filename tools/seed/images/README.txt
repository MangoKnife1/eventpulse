OPTIONAL: put your own event photos here (.jpg, .jpeg, .png, .webp).

The seed script uploads them to your Cloudinary and uses them as event banners.

Layout:
  images/                 -> used for any event
  images/technology/      -> only for Technology events
  images/design/          -> only for Design events
  images/music-arts/      -> only for Music & Arts events
  images/community/       -> only for Community events
  images/gaming/          -> only for Gaming events

Category folders win over the shared folder. If there are no local images,
the script uses online sample photos instead.

Free photo sources (landscape, about 1200x675, under 1 MB each):
  https://unsplash.com   https://www.pexels.com   https://pixabay.com
